## Product surface

Tailpath is an operational canvas, not a marketing dashboard. The desktop
container model is a quiet top bar, a 220-pixel filter rail, a full-bleed graph
canvas, an optional 340-pixel inspector, and an in-canvas legend. Mobile keeps
the top bar, replaces the rail with a compact search/path/recent toolbar, keeps
the graph full width, and opens details as a bottom sheet.

`App` remains composition glue. Topology filtering and element construction
stay in `lib/graph`; Cytoscape rendering and layout stay in `TopologyGraph`;
edge and node detail stay in `Inspector`; the shell owns UI preferences and
selection cleanup.

| Direct       | teal `#16877a`                     |
| DERP         | amber `#bd7b00`                    |
| Peer Relay   | magenta `#a4488e`                  |
| Unknown      | neutral gray `#7f8a91`             |
| warning      | red `#c84d4d`                      |

Use Inter/system sans with zero letter spacing. Brand is 17px; node labels and
controls are 12px; graph rates are 8px; inspector titles are 17px; utility
labels are 8-10px. Controls use square corners or a maximum 6px radius. The UI
uses borders and open rails rather than cards, gradients, glow, or elevation.

## Graph language

Path and activity are independent dimensions:

| Dimension | Encoding                                                          |
| --------- | ----------------------------------------------------------------- |
| Path      | semantic color plus topology/glyph                                |
| Active    | solid line, current arrows, current aggregate rate, rate width    |
| Recent    | dashed line, fixed minimum width, no arrows or rate, 50% emphasis |

Direct has no intermediate marker. DERP passes through a rounded relay node.
Peer Relay passes through its Tailnet relay node. Unknown uses a small `?`
midpoint marker. Path filters and the legend use the same mini-topology glyphs,
so path never relies on color or line pattern alone. Solid/dashed is reserved
exclusively for active/recent state.

An active logical edge has one compact aggregate speed label even when a relay
splits it into two rendered segments. Directional rates remain in the inspector.
Rate-label width, endpoint radii, label padding, and arrow clearance determine
the ideal edge length; the center distance has a deterministic lower bound.

Active width uses one fixed global logarithmic scale, never the current graph's
minimum and maximum:

```text
visual floor = 1 KB/s
visual ceiling = 100 MB/s
minimum width = 1.5px
maximum width = 5.5px
```

Clamp below/above the anchors and quantize to 0.25px to avoid visual jitter.
Recent edges always use the minimum width. At the default view this maps about
100 KB/s to 3px, 2 MB/s to 4.25px, and 10 MB/s to 4.75px.

Runtime telemetry belongs to the Tailnet/tsnet runtime being observed, not to
the reporter process. Mark that node with a small attached teal telemetry badge.
One reporter may export several marked runtime views. Peer-only nodes retain a
neutral body without a telemetry badge.

## UI state

Active relationships are always rendered after path filtering. `Show recent`
is a binary display preference, defaults on, and persists per browser under a
versioned key. It affects only client rendering. Turning it off hides recent
edges and nodes supported only by those edges; if a hidden recent edge is
selected, close its inspector. There is no recent-only mode in v0.1.

Search dims non-matches without changing graph structure. Path filtering and
the recent option hide irrelevant nodes. Selection uses a neutral focus underlay
and must not make a recent edge look active.

## Visible copy

The first viewport may use only the established product and operational copy:
`Tailpath`, node/active-edge/live-runtime metrics, `Live`, `Find node`, `Path`,
path names and counts, `Show recent`/`Recent`, runtime reporting status, legend
group and item names, and the existing inspector fields. Do not introduce
feature explanations, observer/reporter labels, badges, or marketing copy.

Desktop runtime status is `N of N runtimes reporting`. The node legend and
inspector use `Runtime telemetry` and `Peer only`. `Observed by` remains correct
for edge provenance because it names the runtime views supporting that edge.

## Responsive behavior

At 620px and below, hide desktop metrics and the filter rail. Use a 52-pixel top
bar and compact toolbar with icon search, path menu, and visible Recent switch.
Compose the graph for portrait and fit above a compact three-group legend band.
The inspector remains a bottom sheet. Text, nodes, arrowheads, and controls must
not overlap at 412 x 915 or the accepted concept's native 842 x 1869 dimensions.

## Icon inventory

Use the existing Lucide family for brand waypoints, search, live connection,
close, path/detail, clock warning, and traffic directions. The graph telemetry
badge may reuse Lucide Activity geometry in a Cytoscape-compatible image. Path
mini-topology glyphs are CSS/Cytoscape primitives: line, relay rectangle/circle,
and question marker. Device icons remain a later stage.
